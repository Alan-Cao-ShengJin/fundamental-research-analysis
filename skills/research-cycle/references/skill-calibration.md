# Calibrate the research system from examples

Use when the user is teaching, auditing or improving the research skills. The durable output is a change to reusable behavior, supported by a transfer test. A company report is evidence about that behavior; it is not the only deliverable.

## Turn feedback into a portable correction

1. Identify the decision or communication failure, including what already worked. Distinguish missing analysis, unsupported inference, calculation/basis error and presentation error. A request to explain a multiple does not imply that the operating forecast was wrong.
2. Assign the correction to its owner: research-cycle for routing/dependencies; company-model for construction; valuation-thesis for valuation definitions; research-brief for the investment argument. Modify the existing rule instead of adding overlapping skills or repeating it throughout the bundle.
3. Preserve accepted reasoning and explicitly user-authored wording during narrow revisions. Change dependent numbers when an input actually changes. Adding valuation detail must not displace the operating drivers, supporting evidence or strongest counter-case.
4. Abstract the reasoning rather than the issuer: keep company data, sector assumptions, broker choices and selected multiples in the research package. Reusable references and assets use original synthetic cases. A preferred outcome in one example is not a rule to make future cases bullish.
5. Add a reusable calculation only when it prevents a demonstrated recurring error. Add a behavioral evaluation for judgments that arithmetic cannot assess. Link resources from the owning skill so a future run will discover them.

Use existing project records to retain the failure, general lesson, changed owner and verification. A separate calibration report or new filing structure is not required for each edit.

## Verify transfer and resistance to regression

Start with a synthetic evidence pack and ask for a fresh argument without supplying the reference prose or expected call. Review whether the output:

- Explains the decision-driving economics before the detailed target calculation; the compact header may still show the call and target.
- Exposes the assumptions that produce earnings and cash, then explains the gap versus comparable expectations.
- Uses the same earnings basis for each price/P/E calculation and gives a reason for the selected target multiple.
- Retains material contrary evidence and a concrete condition that would weaken the view.
- Publishes investor-useful reasoning while keeping internal rules, source-access logs and validation records in support.

Then introduce a valuation question or new comparison. Check that the stronger operating explanation survives and that the agent does not change forecasts merely to defend the earlier recommendation. Test a materially different economic mechanism as well: a distribution-led case, for example, should explain sustainable cash and required yield rather than copy an earnings-multiple argument.

The [synthetic writing example](../../research-brief/references/calibration-example.md) and [behavioral cases](../../evals/research-cases.md#calibration-preserves-the-operating-argument) support this review. They illustrate reasoning, not required wording, headings or a fixed number of paragraphs. Label a self-review as such; do not claim independent assessment unless it occurred.

A structural check, passing unit tests and a one-page PDF establish different things. None proves analytical quality or forecast accuracy. Retain remaining weaknesses and use later projects and forecast-to-actual comparisons to test whether the correction generalizes. Do not repeatedly regenerate the same issuer PDF when the unresolved issue is the skill itself.
